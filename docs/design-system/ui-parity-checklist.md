# UI Parity Checklist

## Purpose
Use this checklist during the first UI-stub deliverable to ensure the implementation carries the supplied UI design forward rather than drifting into a generic dashboard.

## Global
- [x] Sidebar structure matches the design export.
- [x] Logo block, profile block, and new-client CTA preserve visual placement.
- [x] Primary button color and rounded/shadow treatment match screenshots.
- [x] Orange accent filters/buttons match screenshots.
- [x] Card radius, border color, and shadows match screenshots.
- [x] Page padding and content max widths match screenshots.
- [x] Top search and notification/settings/profile controls match screenshots.
- [x] Typography scale and weight match screenshots.
- [x] All major screens use the generated theme variables.

## Dashboard
- [x] Performance/operations header matches visual hierarchy.
- [x] Revenue and capacity cards match layout and chart treatment.
- [x] Priority tasks card matches orange emphasis.
- [x] Work to-do cards match icon, badge, button, and spacing treatment.
- [x] Live pipeline card matches compact event rows.
- [x] Dark pipeline-stall card treatment is preserved.

## Clients
- [x] Roster stats cards match.
- [x] Search/filter/status controls match.
- [x] Table/card row spacing and status treatment match.
- [x] Profile pages preserve tabs, metric cards, calendar, charts, and modals.

## Forms
- [x] Form template cards match.
- [x] Recent form rows match.
- [x] Builder layout preserves left palette, central preview, and right style panel.
- [x] Form field controls preserve visual hierarchy and drag affordances.

## Training
- [x] Exercise library hero/header matches “Movement Vault” style.
- [x] Anatomy and equipment filters match pill styles.
- [x] Exercise cards preserve image treatment, badges, metadata, and add card.
- [x] Add exercise page preserves two-column cards and large upload panel.

## Nutrition
- [x] Meal plan library hero card matches.
- [x] Active assignments table matches.
- [x] Template cards preserve food imagery and macro tiles.
- [x] Food database search/category/pagination treatment matches.

## Education
- [x] Educational Vault hero typography and resource layout match.
- [x] Feature resource card and side assignment card match.
- [x] Latest resources card grid matches.

## Supplementation
- [x] Supplement library summary cards match.
- [x] Supplement rows preserve timing/pro-tip treatment.
- [x] New protocol slide-in panel matches screenshot.
- [x] Supplement plans active/library tabs match.

## Messaging, Packages, Team, Social
- [x] Messages layout preserves conversation list and active chat panel.
- [x] Package cards preserve color variants and action icons.
- [x] Team management layout preserves task/member surfaces.
- [x] Social media page remains planning/content-calendar only for MVP.

## Accessibility Adjustments
- [x] Any accessibility-driven visual changes are documented.
- [x] Focus rings use theme tokens.
- [x] Icon-only controls have accessible names without visible layout drift.
- [x] Keyboard behavior works for menus, dialogs, drawers, and tabs.
